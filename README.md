# Sonam Wangchuk | Portfolio

Personal portfolio built with HTML, CSS and JavaScript.

Sections: Home, About, Skills, Projects, Education (with certifications) and Contact.
Features: animated "This Is My Portfolio" intro, amber/blue accent switch, mobile menu, project filter and carousel, certificate viewer, copy-email button, responsive layout.

Open `index.html` in a browser to view it locally. Deploy with GitHub Pages (Settings > Pages > Deploy from branch `main`, folder `/root`).
